\section{Realisierung eines Logic Analyzers}

In dieser Aufgabe ist ein Logic Analyzer zu realisieren. Es sollen 3 unbekannte Gatter erkannt werden und im Seriellen Monitor ausgegeben werden.

\subsection{Vorbereitung}

\begin{center}
\logicGate{AND}{0}{0}{0}{1}{$Y = A \wedge B$} \hfill
\logicGate{OR}{0}{1}{1}{1}{$Y = A \vee B$} \hfill
\logicGate{NAND}{1}{1}{1}{0}{$Y = \overline{A \wedge B}$} \hfill
\logicGate{NOR}{1}{0}{0}{0}{$y = \overline{A \vee B}$} \hfill
\logicGate{XOR}{0}{1}{1}{0}{$Y = A \oplus B$}
\end{center}
