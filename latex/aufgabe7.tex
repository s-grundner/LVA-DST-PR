\section{Datenübertragung mittels Infra-Rot (IR)}

Mit zwei Arduino Uno Boards soll eine Übertragung von Morsecodes mittels Infra-Rot Lichtsignalen aufgebaut werden. Sender seitig wird eine IR-LED angesteuert, sodass Infrarotsignale mit einer Frequenz von \SI{38}{\kilo\hertz} gesendet werden. Die Symbole der Morsezeichen (\mdash,\textbullet) werden dabei mit unterschiedlicher Sendedauer enkodiert. Als Empfänger wird das IR-Detektor-Modul KY-022 verwendet, welches am Ausgang \lstinline!LOW! ausgibt, wenn es ein IR-Lichtignal mit der genannten Frequenz detektiert, ansonsten \lstinline!HIGH!.

\subsubsection{Codierung des Morsesignals}

Um die Symbole der Morse-Codewörter zu übertragen, wird mit der Funktion \lstinline!tone(pin, frequency, duration)! ein \SI{38}{\kilo\hertz} Rechtecksignal mit unterschiedlicher Dauer auf dem LED-GPIO Pin ausgegeben. 

\begin{algorithm}[h]
\caption{Ablauf zum Senden der Korrekten Symboldauern in einem Morse-Codewort}\label{alg:tone}
\begin{algorithmic}
\ForAll{Symbols in Codeword}
    \State \lstinline!tone(TX_PIN, F_IR_HZ)!
    \If{Symbol is Dash}
        \State \lstinline!delay(DASH_TIME_MS)!
    \Else
        \State \lstinline!delay(DOT_TIME_MS)!
    \EndIf
    \State \lstinline!noTone(TX_PIN)!
    \State \lstinline!delay(INTER_SYMBOL_TIME_MS)!
\EndFor
\State \lstinline!delay(PAUSE_TIME_MS)!
\end{algorithmic}
\end{algorithm}

Damit die Methode \lstinline!tone()! funktioniert, muss der Pin ein PWM Pin sein, z.B. 3 oder 11. Um die richtigen Symboldauern für die Symbole in einem Morse-Codewort zu senden, kann ein Ablauf wie in Algorithmus \ref{alg:tone} verwendet werden.

Für die IR-Diode soll sich im Betrieb ein Arbeitspunkt von $I=\SI{130}{\milli\ampere}$ und $U_F=\SI{1.6}{\volt}$ einstellen. Um den Strom durch die Diode einzustellen, muss der Widerstand $R_2$ passend dimensioniert werden.

Die restliche Spannung die nicht über die Diode abfällt, muss über $R_2$ und $R_\text{DS,on}$ abfallen. Mit $R_{\text{DS,on}}=\SI{14}{\ohm}$ ergibt sich:
\[
R_2 = \frac{\SI{5}{\volt} - \SI{1.6}{\volt}}{\SI{130}{\milli\ampere}} - R_\text{DS,on} = \SI{12.15}{\ohm}
\]

Um den Maximalstrom nicht zu überschreiten, wird der nächst höhere Widerstand aus der E6 Reihe mit $R_2 = \SI{15}{\ohm}$ gewählt.

\subsubsection{Implementierung des Senders}

Um die Buchstaben im Alphabet auf Morsecodewörter umzuwandeln, wird eine Tabelle verwendet, welche die Zusammensetzungen von Dots und Dashes, sowie die Länge des jeweiligen Codewortes speichert. Der Code wird als eine binäre Zahl gespeichert, dabei korrespondiert eine 0 zu einem Dot (\mdot) und eine 1 zu einem Dash (\mdash). In einem Enum werden die Anzahl an Zeiteinheiten (\lstinline!UNIT!) definiert, die für jedes Symbol gelten soll. Die Konstante \lstinline!UNIT_LEN_MS! definiert, wie lange eine Zeiteinheit sein soll.

\lstinputlisting[

\newpage
Zum Senden wird zuerst überprüft ob der Eingabewert im Alphabet ist und ermittelt, an welcher Position im \lstinline!morseTable! er sich befindet. Der Morsecode wird in einer Schleife mit der Länge des Codewortes durchlaufen. Mit jeder Iteration wird der \SI{38}{\kilo\hertz} Ton am TX-Ausgang aktiviert. Ist das momentane Symbol \lstinline!1!, also ein \mdash, wird die definierte Dauer für einen Dash mittels \lstinline!delay()! gewartet, sonst die für einen \mdot. Danach wird der Ton mit \lstinline!noTone()! wieder ausgeschalten. Nach jedem Symbol wird eine definierte Zeit zwischen den Symbolen verzögert. Nach dem Codewort wird eine definierte Pausezeit gewartet.

\subsubsection{Implementierung des Empfängers}

Hier wurden die Schwellwerte für die Symbole festgelegt. Dabei bedeuten \lstinline!DOT_THRESH_US!, dass alle empfangenen Symbole unter dieser Messdauer als \mdot gelten und Messdauern die sich zwischen \lstinline!DOT_THRESH_US! und \lstinline!DASH_THRESH_US! befinden als \mdash.

Zur Dekodierung des Codewortes wird ein Binärer Suchbaum verwendet. Es werden laufend Symbole empfangen. Ist das Symbol ein \mdot wird der rechte Pfad gewählt, sonst der linke. Wird das Codewort mit einer Pause beendet, wird der Buchstabe an der aktuellen Position im Baum.
